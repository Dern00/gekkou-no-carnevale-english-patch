Gekkou no Carnevale English Patch v1.1

Install

1. Close Gekkou no Carnevale and back up your save files.
2. Extract this entire ZIP into a folder outside your game folder.
3. Open Gekkou no Carnevale English Patch.exe, browse to the original
   Japanese GekkounoCarnevale.exe, and click Install patch.
4. Launch GekkounoCarnevale.exe from the game folder.

The installer can patch a supported original v1.00 or v1.01 Windows copy.
On v1.00 it downloads Nitroplus's official v1.01 updater and verifies the
files before installing them. If the download fails, download the official
Carnevale101.EXE and put it beside the patch installer before trying again.
An already-updated v1.01 copy can be patched offline.

Official v1.01 update
https://www.nitroplus.co.jp/support/sp12/374.php

Included

The English retranslation, translated interface, September 2026 menu
crash fix, expanded text boxes, backlog ruby readings, and the optional
Stop voice on click setting under Settings > Text.

Older saves can retain their first displayed page and backlog text.
A new game gives you a clean English backlog.

Restore

Close the game. Open the patch installer, choose the same game folder,
and click Restore original files. Keep the game's Before Carnevale
combined patch folder for restoration.

Opening subtitles

The installer now adds timed English and romanized Japanese subtitles
to the opening automatically. The portable renderer is included.
Restore original files restores the opening if this installer changed it.
See OPENING-SUBTITLES.md for details.

The portable renderer is FFmpeg 9.1, licensed under the LGPL v2.1 or later.
See FFMPEG-BUILD.md for build instructions. The corresponding source archive
is attached to the GitHub v1.1 release.
