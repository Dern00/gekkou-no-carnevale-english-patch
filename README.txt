Gekkou no Carnevale English Patch v1.1
Combined manual installation

This patch works with the original Japanese Windows game, v1.00 or v1.01.
It includes Nitroplus's v1.01 update and the English patch, including the
Windows menu crash fix. The opening movie stays as installed.

Install
1. Close the game.
2. Find the folder containing GekkounoCarnevale.exe. Back up any existing
   copies of 0cg.pak, script.pak, system.pak, 0script.pak, and system.dll.
3. Extract those five game files directly beside GekkounoCarnevale.exe.
   Accept replacement when prompted. Keep this README wherever you like.
4. Launch GekkounoCarnevale.exe as usual.

Remove the patch
Close the game and restore the files you backed up. Remove any of the five
game files that were absent before installation.
