# Opening subtitles

The installer now adds timed English and romanized Japanese subtitles to the opening automatically. The romanized lyrics appear at the top and the English lyrics at the bottom.

The bundled renderer checks the stock `mpeg\OP.mpg` and adds subtitles while copying the original audio. The original movie is backed up in the game folder. **Restore original files** restores the movie alongside the other game files.

If you used the v1.0 optional opening helper, v1.1 recognizes its subtitle movie. Use that helper’s restore command if you want to undo its separate installation. [v1.0 opening helper instructions](https://github.com/Dern00/gekkou-no-carnevale-english-patch/blob/v1.0/OPENING-SUBTITLES.md).
